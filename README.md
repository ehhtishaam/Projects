# Projects

Standalone coursework and personal projects, organized by project. Each folder is self-contained with source code and a short write-up.

## 📁 Projects

🔹 **Java Secure Authentication System**
A secure authentication system built in Java, implementing SHA-256 password hashing, breach detection, and password policy enforcement.

🔹 **DSA Library Management System**
An online library management system built in C++, using a Binary Search Tree for efficient record storage and retrieval.

🔹 **Password Strength Checker**
A terminal-based password validation utility built to analyze password complexity, structural entropy, and cross-reference against known credential leaks.

🔹 **Caesar Cipher Encryption/Decryption**
A classic substitution cipher implementation demonstrating the Input → Process → Output model used in cryptographic systems.

🔹 **Phishing Scenario Triage**
Analysis of three realistic phishing scenarios with red-flag identification and a Pause → Verify → Report decision framework for responding to suspicious messages.
